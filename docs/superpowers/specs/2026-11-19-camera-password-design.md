# Пароль и журнал камер — решение (19.11.2026)

**Зачем.** Сейчас любой компьютер в той же сети смотрит и крутит любую камеру. Нужен пароль; лазейка для взлома —
позже, в пункте 6 (подбор слабого пароля и т. п.). Снимки/запись/письма — не просьба автора, не делаем.

**Решено с автором (макет https://claude.ai/artifact/Uc6wvmsnGuvL5Yaojzrofp одобрен):**
- Пароль ставит/убирает игрок в окне камеры (ПКМ) — кнопка «🔒 Доступ», панель на месте картинки: поле, оценка
  надёжности, «Сохранить», «Убрать пароль», журнал. Рядом с камерой пароль не нужен.
- По сети: камера с паролем видна в списке, но закрыта; компьютер вводит пароль (`camera.login`), Wired-«Камеры» и
  `cam` спрашивают и по умолчанию запоминают на этом компьютере (`/home/.cameras`).
- Журнал: последние 50 попыток входа по сети — время, адрес, имя компьютера, пустили/нет.
- Смена пароля выкидывает всех смотрящих (их сохранённый пароль больше не подходит).

**Как устроено (решения Claude):**
- Камера хранит не пароль, а его отпечаток (SHA-256) — в мир и игрокам пароль не уходит; клиент получает только
  «закрыта/открыта», журнал — по запросу из окна.
- Компьютер помнит введённые пароли в памяти (по адресу камеры); каждое обращение (кадр, поворот, настройка)
  сверяется с текущим отпечатком камеры.
- Неверный пароль — следующая попытка с того же адреса не раньше чем через 1 с (не пишется в журнал). Без этого
  4 цифры подбирались бы программой мгновенно; настоящий «взлом» — в пункте 6.
- Камера без пароля работает как раньше (старые постройки не меняются).
