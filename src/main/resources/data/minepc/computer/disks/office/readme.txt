Офис для Wired 1.0: Документы (.wdoc) и Таблицы (.wtab).

Документы — заголовки, списки, цитаты, цвет и выделение текста.
Таблицы — формулы: =A1+B2, =СУММ(A1:A10), =СРЗНАЧ(B2:B5), =ЕСЛИ(A1>10;"много";"мало"),
МИН, МАКС, СЧЁТ, ОКРУГЛ, МОДУЛЬ, КОРЕНЬ, СЦЕП, ДЛСТР. Несколько листов, диаграмма выделенного.
