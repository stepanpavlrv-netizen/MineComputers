Камеры для Wired 1.0

Ищет камеры в сети и показывает их: по одной, сеткой 2×2 и 3×3, все сразу
или по очереди (каждые N секунд). У открытой камеры — поворот, зум,
ночное видение, патруль, качество и частота. Без Wired — программа cam.

Камера с паролем: в списке — «закрыта паролем»; при открытии программа
спросит пароль и (если не снять галочку) запомнит его на этом компьютере.
